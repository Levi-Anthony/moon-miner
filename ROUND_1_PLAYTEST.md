# Round 1 Playtest Tracker

Status: paused, 0/5 sessions complete.

Pause reason: this tracker targets the V0 grid prototype. The active direction has shifted to the continuous-motion nano-field concept in `CONCEPT_REFRAME.md`, so running these sessions now would answer the wrong research question.

Resume only if:

- The user explicitly wants to study why the grid prototype drifted from intent.
- A continuous-motion prototype exists and this tracker is rewritten for that build.
- The research question is reframed away from grid comprehension and toward live-action motion, drone launch timing, prepared-field mining, and emergency crawl.

Build: local Vite dev server at `http://localhost:5173/`
Seed: `apollo-17`
Round bet: A first-time player can understand movement, auto-printing, nanobot scarcity, reclaiming, mining, and fair failure well enough to attempt the core loop without being directly taught the solution.

## Participant Mix

- P1: puzzle/strategy player
- P2: puzzle/strategy player
- P3: casual player
- P4: casual player
- P5: rare/non-player

## Moderator Setup

Before each session:

1. Open `http://localhost:5173/`.
2. Confirm the mission briefing is visible.
3. Record browser/device, audio on/off, and whether screen/audio recording is permitted.
4. Say: "We are testing the game, not you. Confusion is useful."
5. Ask background:
   - What kinds of games do you play, if any?
   - Have you played top-down, puzzle, mining, or logistics games?
   - How comfortable are you with keyboard controls?

Task prompt:

> Please start a run and try to complete the mission. Use whatever the game gives you. Say what you are thinking for the first few minutes.

Moderator rules:

- Do not say how to move, reclaim, mine, or queue routes.
- Prompt only with "What are you thinking?" or "What makes you say that?"
- If stuck for 90 seconds, ask "What options do you think you have?"
- If still stuck, use the smallest hint from `PLAYTESTING.md` and mark it in the trace.
- Separate observation from interpretation.

## Success Criteria

- 4/5 players start moving within 30 seconds after briefing.
- 4/5 understand nanobots are consumed by auto-printing.
- 3/5 discover or correctly explain reclaiming without being taught directly.
- 3/5 use or understand queued destination driving.
- 3/5 can describe the goal after playing.
